# სტუდენტური ცვლები — დემო

სტუდენტი რეგისტრირდება, კალენდარში ლექციებს მონიშნავს და ხედავს მხოლოდ იმ ვაკანსიებს, რომელთა ცვლები მის თავისუფალ საათებში ჯდება. AI ასისტენტი (ლოკალური Ollama) შესაფერისი ვაკანსიებიდან ურჩევს საუკეთესოს.

## გაშვება

საჭიროა Node.js 20+ და Ollama.

```bash
npm install
ollama pull llama3.2
npm run dev
```

გახსენი მისამართი, რომელსაც ტერმინალი გაჩვენებს (ჩვეულებრივ http://localhost:5173).

Windows-ზე Ollama ინსტალაციის შემდეგ ფონურად თავად ეშვება. თუ ასისტენტი წერს, რომ კავშირი ვერ დამყარდა, ცალკე ტერმინალში გაუშვი `ollama serve`.

## როგორ მუშაობს

- **შესაბამისობა კოდში ხდება, არა AI-ში** (`src/lib/match.js`). ცვლა ერგება, თუ მის არცერთ საათში ლექცია არ არის. ტესტები: `npm test`.
- **AI** (`src/lib/ollama.js`) იღებს მხოლოდ უკვე გადარჩეულ ვაკანსიებს, ამიტომ არარსებულ სამსახურს ვერ მოიგონებს. მოთხოვნა Vite-ის proxy-ით მიდის `localhost:11434`-ზე (`vite.config.js`), ამიტომ CORS-ის პრობლემა არ არის.
- **მოდელი** ასისტენტის ფანჯარაში იცვლება (მაგ. `qwen2.5`). llama3.2 ქართულად სუსტად წერს, EN რეჟიმი უფრო სტაბილურია.
- **მონაცემები** მხოლოდ ბრაუზერში (localStorage) ინახება. სერვერი არ არის.
- **ვაკანსიები** დემოა: `src/data/jobs.js`.
