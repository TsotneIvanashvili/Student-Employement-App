# Shiftmate

დამატებითი სამუშაო შენს თავისუფალ დროში. მაძიებელი კალენდარში წერს, როდის არის დაკავებული, დამსაქმებელი აქვეყნებს ვაკანსიას ცვლის დღეებითა და საათებით, პლატფორმა კი აჩვენებს მხოლოდ იმ ვაკანსიებს, რომლებიც თავისუფალ დროში ჯდება.

- საიტი: https://shiftmatee.vercel.app
- სტეკი: React + Vite + Tailwind, Supabase (ავტორიზაცია, Postgres + RLS, ფაილები), Vercel (ჰოსტინგი + `/api/chat`), Groq (AI ასისტენტი)

## გაშვება

```bash
npm install
npm run dev      # http://localhost:5173 (AI ლოკალურად Ollama-ს იყენებს: ollama serve)
npm test         # ლოგიკის ტესტები (დამთხვევა, განრიგი, AI-ს პასუხის გარჩევა)
npm run build
```

## გაშვებამდე შესამოწმებელი (ხელით)

1. **Supabase → Authentication → URL Configuration:** Site URL = საიტის მისამართი; Redirect URLs-ში დაამატე `https://<დომენი>/**`. ამის გარეშე დადასტურებისა და პაროლის აღდგენის ბმულები არასწორ მისამართზე გადავა.
2. **Supabase → Authentication → SMTP:** ჩაშენებული ფოსტა საათში რამდენიმე წერილით არის შეზღუდული. ნამდვილი მომხმარებლებისთვის მიაბი საკუთარი SMTP.
3. **Supabase → Authentication → Passwords:** ჩართე გაჟონილი პაროლებისგან დაცვა.
4. **`src/lib/config.js`:** `SITE_URL` და `CONTACT_EMAIL` (ცარიელი ელფოსტისას საიტზე კონტაქტის ბლოკი არ ჩანს). დომენის შეცვლისას გაასწორე `public/robots.txt`, `public/sitemap.xml` და `index.html`-ის `og:` ბმულებიც.
5. **Vercel → Environment Variables:** `GROQ_API_KEY` (სავალდებულო), `GROQ_MODEL` (არასავალდებულო).
6. **წესები და კონფიდენციალურობის პოლიტიკა** შაბლონია: გაშვებამდე იურისტმა უნდა გადახედოს.
7. ბაზაში „(დემო)“ კომპანიების ვაკანსიები სატესტოა: ნამდვილი გაშვებისას წაშალე.

## გადახდები

გადახდის სიმულაცია გამორთულია: მხარეები ანაზღაურებაზე პირდაპირ თანხმდებიან. `payments` ცხრილი და `hire_and_pay` / `release_payment` ფუნქციები ბაზაში რჩება, მაგრამ მათი გამოძახება აკრძალულია. ნამდვილი გადახდებისთვის საჭიროა ლიცენზირებული პროვაიდერი.
